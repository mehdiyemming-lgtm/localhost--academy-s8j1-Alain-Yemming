## Définitions

**Classe :** Une classe est un modèle (un plan) qui décrit les attributs et les méthodes communs à un ensemble d'objets.

**Objet :** Un objet est une instance d'une classe, c'est-à-dire un élément concret créé à partir de ce modèle, avec ses propres valeurs.
